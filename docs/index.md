# Chattd (pronounced as "Chatted")

Real-time chat application with WebSocket support, rate limiting, and role-based room access.

Stack: Python 3.12+, FastAPI + Uvicorn, SQLAlchemy (async) + Alembic, WebSockets, vanilla HTML/JS/CSS.
